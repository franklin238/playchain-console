# GLOAM: VESPER credits

Created by Steeve (@gamersteeve). Made for Gloam: private money on public chains.

- Built with Phaser 3 (MIT licence).
- Narrator voice: Kokoro (Apache 2.0).
- Pixel font: Pixelify Sans (SIL Open Font License).
- Music and sound are made in the browser as you play.

`index.html` is the game's single-file build from its own repository (`npm run share` in GLOAM VESPER), wrapped by `web/scripts/wrap-vesper.mjs` so it can save through PlayChain. To update the game, rebuild the single file there and run:

```bash
node scripts/wrap-vesper.mjs "<path to GLOAM VESPER.html>"
```

`cover.png` is the game's own title screen.
