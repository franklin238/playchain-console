# Hollow Kingdom credits

Developer: Steeve (@gamersteeve)

- No vendored libraries. Plain HTML, CSS and JavaScript (canvas 2D + Web Audio API).
- All assets generated in code: every graphic is drawn at runtime with the canvas API, and all music, ambience and sound effects are synthesised at runtime with the Web Audio API.
- No external fonts (system font stack), no samples, no network requests.
- cover.png is a screenshot of the game's own title scene.
