# Signal Lost credits

Game design and development: Steeve (@gamersteeve) for PlayChain.

All assets generated in code:

- Graphics: drawn at runtime with the Canvas 2D API (no image files, no fonts; system font stack).
- Music, static ambience and sound effects: synthesized at runtime with the Web Audio API.
- Levels: handcrafted ASCII layouts plus seeded generator output, verified by the built-in solver (tools/build-levels.mjs, tools/verify-levels.mjs).
- Radio log text: original writing.

No third-party libraries are vendored. cover.png is a screenshot of the game's own title screen.
